- **대체 경로**: 정책적으로 다른 지수를 쓰는 안(PM 결정 필요)
- **직접 계산 가능**: 불가/미확인
- **다음 행동**: ① 지수 공식 정의 · PR/TR 확인 ② 정책(대장 P-12) 정리 후 Index Master 등록 여부 결정 ③ 등록해도 D-1(본국 보통주)이 먼저 확정돼야 실제로 쓰인다.
