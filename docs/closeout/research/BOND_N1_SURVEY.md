## 1. 현재 앱이 채권을 다루는 방식 (코드에서 확인한 사실)

| 항목 | 현재 동작 | 근거 |
| --- | --- | --- |
| 자산 분류 | `ASSET_CATEGORIES`에 `채권` 존재 | js/01 `ASSET_CATEGORIES` |
| 시세 조회 | **하지 않는다** — `채권`은 `NON_TRADABLE_CATEGORIES`(채권 · 현금 · 부동산) | js/01:173 |
| 이름에 채권이 들어간 종목 | **티커가 있으면 `ETF`로 분류**해 시세를 받고, 티커가 없는 직접보유 채권만 `채권`으로 남긴다 | js/01:411~414 |
| Risk 진단 대상 | `RISK_ELIGIBLE_CATEGORIES = ['주식','ETF']` → **직접보유 채권은 Risk에서 아예 빠진다**. 채권 ETF는 들어오지만 Benchmark가 없어 베타를 못 구한다 | js/09:573 · 739 |
| 포트폴리오 베타 | 베타를 못 구하는 종목이 하나라도 있으면 null → **채권 ETF 1개만 있어도 null**(대장 M-5) | §44 제10조 |
| 미래예측 | 성격 `BOND` · 그룹 기본 수익률 4.0% · Return Key `BOND` | js/05 |
| MC | 채권 · 현금 **σ = 0**(§7 정책 · BOND-DEF-03) | 체크리스트 §7 · §9-2 |
| 직접 입력 채권 가격 | 자동 갱신되지 않는다(안내도 없다 · 대장 F-4 · BOND-DEF-02) | §9-2 |

**요약**: 지금 구조는 채권을 "가격이 움직이지 않는 잔액"처럼 다룬다. 식별 · 분류 · 수익률 가정 계층에는 자리가 있지만 **위험 계층에는 자리가 없다.**

## 2. 대상 자산 유형과 필요한 사실

| 유형 | 예 | 앱에서의 현재 위치 | 필요한 최소 사실 |
| --- | --- | --- | --- |
| A-1 국채 · 지방채 | 국고채 10년 | 직접 입력(`채권`) | 식별자(표준코드/ISIN) · 발행인 · 통화 · 만기 · 표면금리 · 이자지급주기 · 평가가격 · 수익률(YTM) · 듀레이션 |
| A-2 회사채 · 금융채 | 은행채 · 여전채 | 직접 입력 | A-1 + **신용등급** · 신용스프레드 |
| A-3 외화채권 | 미국채 · 달러 회사채 | 직접 입력 | A-1/A-2 + 표시통화 · 환헤지 여부 |
| B 채권 ETF | TLT · IEF · KODEX 국고채 | `ETF`(시세 있음) | 기초지수 · 지수 유형(총수익/순가격/시장가격) · 평균 듀레이션 · 신용구성 · 통화 · 환헤지 |
| C 채권혼합 ETF | 237370 · 472170 | `ETF`(MIXED) | 주식/채권 구성비(확인 완료) · 채권 부분의 지수 · 듀레이션 |
| D 현금성 | MMF · 파킹형 | `현금` 또는 ETF | 해당 없음(σ=0 유지 후보) |

> 직접보유 채권(A)은 **사용자 입력 외에 자동으로 채울 수 있는 사실이 거의 없다** — 식별자 표준화가 선행되어야 외부 조회가 가능하다.

## 3. 경제적 정의 후보 비교 (PM 지시 §11)

| 관점 | ① 만기보유(HTM) | ② 시가평가(MTM) | ③ 통합 표현(혼합) |
| --- | --- | --- | --- |
| 평가액 | 취득가 + 경과이자(또는 상각후원가) | 시장가격 × 수량 | 사용자가 보유 의도를 선택 · 화면에는 둘 다 표시 |
| 금리 상승 | 평가액 영향 **없음**(만기 상환액 고정) | 평가액 **하락**(듀레이션 × 금리변화) | 의도에 따라 다르게 표시 |
| 금리 하락 | 영향 없음 | 평가액 상승 | 위와 같음 |
| 신용스프레드 | 부도 시에만 영향 | 즉시 평가액 반영 | 위와 같음 |
| 환율(외화채) | 원리금 환산 시 반영 | 매일 반영 | 둘 다 반영 |
| Risk 의미 | "변동성 0"이 **사실에 가깝다**(보유 의도상) | 주식과 같은 축에서 비교 가능 | 사용자 혼란 위험 ↔ 정확성 |
| MC 입력 | 확정 수익률(YTM)에 가까움 · σ 작음 | 자산군 σ · 상관 사용 | 계좌/자산별 분리 필요 |
| 데이터 요구 | **적다**(만기 · 쿠폰 · 취득가) | **많다**(일별 평가가격 또는 지수 · 듀레이션) | 많다 |
| 사용자 이해 | 쉽다("만기까지 들고 있으면 얼마") | 어렵다(왜 채권이 손실?) | 설명이 필요하지만 가장 정직 |
| 현재 앱 | 사실상 ①에 가깝다(σ=0 · 시세 미조회) | — | — |

**조사 의견(결정 아님)**: 이 앱은 "가구 자산 관리 + 장기 계획" 목적이므로, 직접보유 채권은 ①을 기본으로 두되 **금리 시나리오에서만 ②의 관점을 별도로 보여주는** ③의 축소형이 데이터 요구와 사용자 이해의 균형점으로 보인다. 다만 이는 PM 결정 사항이다.

## 4. Risk 모델 후보 (PM 지시 §12 · 주식 베타 복사 금지)

| 후보 | 계산 | 필요한 데이터 | 한계 |
| --- | --- | --- | --- |
| R-1 듀레이션 × 금리변화 | ΔP/P ≈ −D_mod × Δy | 수정듀레이션 · 금리 시계열 | 듀레이션을 사용자 입력에 의존하면 품질이 들쭉날쭉 |
| R-2 스프레드 듀레이션 | ΔP/P ≈ −D_spread × Δspread | 신용등급별 스프레드 시계열 | 국내 회사채 스프레드 시계열 확보 필요 |
| R-3 채권지수 기반 | 보유 채권을 대표 지수(예: KTB 10년)에 매핑해 지수 수익률로 변동성 · MDD 산출 | **KRX 채권지수 일별 시계열**(아래 5절 · 확보 가능) · 매핑 규칙 | 개별 채권의 고유 위험(신용 · 유동성)은 반영 못 함 |
| R-4 채권 ETF 자체 시계열 | 이미 가격이 있는 ETF는 지금의 변동성 · MDD 계산을 그대로 적용 | 없음(이미 있음) | Benchmark(지수)가 없으면 베타만 불가 — 현재 상태 |
| R-5 YTM 변화 기반 | 평가수익률 변화로 직접 계산 | 종목별 일별 평가수익률(유료 평가사) | 라이선스 비용 |

**현실적 조합 후보**: 채권 ETF는 **R-4 + (지수 확보 시) R-3**, 직접보유 채권은 **R-1**(듀레이션을 사용자 입력 또는 만기 기반 근사) — 단 근사를 쓰면 그 사실을 화면에 명시해야 한다.

> 주의: 포트폴리오 베타 문제(M-5)는 Bond 모델과 별개다. 채권에 "주식 베타"를 억지로 부여하는 방식은 채택 후보에서 제외한다.

## 6. MC 후보 (PM 지시 §13 · 현재 계산식 변경 없음)

| 입력 | 후보 | 비고 |
| --- | --- | --- |
| 기대수익률 | ① 현행 Return Key(`BOND` 4.0%) 유지 ② 보유 채권의 YTM ③ CMA 채권 자산군 기대수익률 | ②는 만기까지 보유 가정과 정합적 |
| 변동성 | ① 현행 σ=0 유지 ② 채권지수 실측 변동성 ③ CMA 채권 σ | ②는 5절 데이터가 있어야 가능 |
| 상관 | ① 현행(σ=0이라 무의미) ② CMA 상관행렬의 채권 항목 | CMA에는 이미 채권 자산군이 있다 |
| 자산군 매핑 | 직접채권 · 국내채권ETF · 해외채권ETF를 각각 어느 CMA 자산군에 붙일지 | `data/cma/app-asset-class-map.json` 확장 검토 |
| 외화채권 FX | 현재 MC에 환율 모델이 없다(C-2와 동일 문제) | C-2 결정에 종속 |
| 헤지비용 | 자료 없음 → 0으로 두지 않는다(§44 6-3) | C-2와 함께 |
| 롤다운 | 만기 접근에 따른 수익 효과 | 2차 이슈 · 지금 범위 아님 |

**중요**: σ=0을 바꾸면 MC 결과가 바뀐다 → 반드시 별도 PM decision package + 동일 seed before/after. 이번 pass에서는 아무것도 바꾸지 않았다.

## 7. 혼합형 상품 (PM 지시 §14)

- 237370 = KRX 배당성장 채권혼합지수(코스피 배당성장 50 **30%** + KTB **70%**)
- 472170 = FnGuide 미국테크TOP10 채권혼합지수(Indxx US Tech Top10 + KIS 국채 3-10년 총수익 **5:5** · 2025-10-31부터 4:6에서 변경)
- 두 상품 모두 **운용사가 단일 혼합지수를 기초지수로 사용**한다.
- 따라서 **1:N 노출 엔진을 지금 만들지 않는다.** 대장 **D-13의 기본 결론은 "현행 MIXED 구조 유지"**로 기록한다.
- 재검토 조건: Bond 모델이 확정되어 "채권 부분의 금리 민감도"를 Risk/MC에 반영해야 할 때, 혼합지수의 내부 구성비(30/70 · 5:5)를 쓸지 다시 판단한다.
